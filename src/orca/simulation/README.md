## Simulation
This folder contains scripts for simulating the geometries generated by ORCA/geometry.

- [`gds_converter.py`](gds_converter.py) — turns a GDS file into a Palace model (mesh + config) with gds2palace.
- [`simulate.py`](simulate.py) — runs one Palace simulation (`run_palace`) and converts its results to a Touchstone file. Output is discarded unless `save_log=True` (then `palace.log` in the simulation folder); stderr is shown on failure.
- [`launchers.py`](launchers.py) — decides *where* simulations run: `SimulationLauncher` exposes *slots* that each run one simulation at a time (a whole node, a socket or a NUMA domain, see `cpu_domains`); `LocalLauncher` runs on this machine, optionally several at once pinned with `numactl`.
- [`slurm.py`](slurm.py) — everything Slurm-specific: `SlurmLauncher` runs simulations as `srun` job steps pinned to a node and its cores (one per node, socket or NUMA domain), including the pre-flight check and `palace-*.bin` resolution.
- [`combine_snp_results.py`](combine_snp_results.py) — Touchstone post-processing.

`PalaceSimulator` (pipeline stage) picks the launcher from its `launcher`/`num_parallel_sims`/`bind` arguments and keeps one worker per slot.
